# Instructions for Codex in this repository

Read `PROJECT_CONTEXT.md` before planning or changing code. Treat it as the shared product, architecture, API, milestone, and collaboration context.

- Start by inspecting current files and `git status`; never assume the repository is empty or discard untracked work.
- Work only on the specific small milestone and file scope requested by the developer. Do not build the whole app at once.
- Briefly explain significant changes before making them, and explain important architecture decisions in plain language.
- Keep changes reviewable; run checks appropriate to the changed code and show the result.
- Let the humans practice Git: do not commit, push, merge, or create pull requests unless explicitly asked for that specific action.
- Run Git commands from this `Insta-Reals/` repository. The parent folder is a separate Git repository and is not the shared project.
